# Handoffs

Contexto de passagem entre IAs/sessões, um arquivo por handoff:
`YYYY-MM-DD_<tema>.md` (template `.claude/templates/handoff.md`).

Escreva handoff quando: uma tarefa estrutural fica pela metade, uma decisão
depende de outra IA, ou a próxima sessão precisaria de mais de 5 minutos para
reconstruir o estado só pelo changelog.
