A rodada `eea99938...` demonstrou mecanismo, host e pilotos e emitiu `LOCAL_QUALIFIED`, mas a auditoria posterior do pacote encontrou path de home residual no SHARE. Por isso o resultado é histórico e não aceito como liberação B0.

O sandbox B0 é deliberadamente estreito: Python audit hook aplicado apenas aos comandos Python allowlisted das tasks da campanha. Ele permite escrita no scratch exclusivo da task e bloqueia escrita externa, subprocessos e rede. Isso não é um sandbox genérico de SO e não autoriza automaticamente comandos futuros B1 que precisem dessas capacidades.

A corretiva V2 mantém RAW imutável, sanitiza repo root/home para marcadores neutros e reprova home paths residuais no SHARE. O próximo gate é fail-fast: preflight → 84 metatestes → coverage → freeze_prepare → novo freeze → uma única rodada de `b0_release`. O B0 só pode ser aceito se o novo release for `PASS/LOCAL_QUALIFIED`, o host continuar PASS e a auditoria do SHARE V2 estiver limpa.
