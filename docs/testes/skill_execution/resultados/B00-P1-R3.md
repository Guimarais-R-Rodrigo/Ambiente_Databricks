## Achados analíticos independentes do enforcement

1. **Alto — códigos postais tratados como variáveis contínuas.** `pickup_zip` e `dropoff_zip` entram em média, desvio, quartis, IQR, correlações e histogramas por serem `integer`. Código postal é identificador/categoria nominal; distância numérica entre códigos não possui interpretação quantitativa direta.
2. **Alto — outliers geográficos derivados de IQR numérico de ZIP.** O notebook rotula 10,0% dos `pickup_zip` e 12,6% dos `dropoff_zip` como outliers via 1,5×IQR. O critério é inadequado para códigos nominais e contamina o resumo de “outliers geográficos”.
3. **Alto — correlações com ZIP são semânticamente inválidas.** Relações como `trip_distance ↔ pickup_zip = 0.49` e `pickup_zip ↔ dropoff_zip = 0.33` são calculadas a partir da codificação numérica arbitrária e depois interpretadas como efeito de localização. Isso não mede associação geográfica válida.
4. **Alto/médio — contagem de tarifas negativas não é demonstrada.** O código de estatística calcula `zeros`, min/max e quartis, mas não conta `fare_amount < 0`; ainda assim o resumo afirma exatamente 5 tarifas negativas. O mesmo output mostra `zeros = 5`, criando risco de confusão entre zeros e negativos.
5. **Médio/alto — qualidade geral superafirmada.** `Qualidade excepcional` é inferida essencialmente de 100% de completude, sem validação de chave/duplicidade, consistência temporal, domínios ou execução de `data_quality_check`.
6. **Médio — limitação temporal falsa.** O resumo afirma que não há informação de horário do dia/dia da semana, mas há duas colunas timestamp completas; essas features são deriváveis dos dados já carregados.
7. **Médio — causalidade/negócio além da evidência.** A correlação distância×tarifa é usada para sugerir “sistema de precificação consistente” e as correlações numéricas com ZIP para sugerir influência secundária de localização. A EDA não demonstra causalidade nem regra tarifária.
8. **Médio — hipóteses geográficas apresentadas como fatos.** Códigos são rotulados como Manhattan/periferia e outliers são atribuídos a aeroportos/bairros periféricos sem mapeamento geográfico no notebook.
9. **Médio — análise de granularidade/chave ausente.** Não há teste de duplicidade completa nem candidata a chave, embora a skill exija validar granularidade antes de concluir qualidade/handoff.
