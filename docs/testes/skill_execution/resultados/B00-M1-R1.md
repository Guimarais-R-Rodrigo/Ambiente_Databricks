## Achados analíticos independentes do enforcement

1. **Alto — ZIPs tratados como variáveis contínuas.** `pickup_zip` e `dropoff_zip` entram no conjunto numérico por dtype e recebem média, quartis, correlação e visualização contínua. Código postal é categoria/identificador nominal; distância entre códigos não possui interpretação métrica direta.
2. **Alto — correlações com ZIP são semanticamente inválidas.** O notebook interpreta `trip_distance ↔ pickup_zip = 0.488`, `fare_amount ↔ pickup_zip = 0.406`, `trip_distance ↔ dropoff_zip = 0.371` e `pickup_zip ↔ dropoff_zip = 0.325` como relações espaciais. Pearson sobre códigos nominais não mede associação geográfica válida.
3. **Alto/médio — análise categórica omite os ZIPs.** A identificação de categóricas considera somente `StringType`, portanto os ZIPs inteiros não entram na análise categórica apesar de sua semântica nominal.
4. **Alto/médio — “histograma” não usa bins.** O código anuncia bins, mas executa `groupBy(col).count().orderBy(col).limit(100)`. Para variáveis com alta cardinalidade, isso mostra apenas até 100 valores ordenados e pode truncar a distribuição de forma material.
5. **Médio/alto — qualidade geral superafirmada.** O resumo classifica `Qualidade — Excelente` após verificar nulos e duplicatas completas, mas sem domínio/ranges, consistência temporal, regras de negócio abrangentes ou `data_quality_check`.
6. **Médio/alto — zero duplicatas completas é transformado em “todas as viagens são únicas”.** Ausência de linhas integralmente idênticas não prova unicidade de uma chave de negócio; as próprias colunas de timestamp têm cardinalidade inferior a 100%.
7. **Médio — unidade `km` é introduzida sem suporte observável.** O schema/metadata exibido não declara unidade para `trip_distance`, mas o resumo passa a reportá-la em quilômetros.
8. **Médio — correlação é convertida em regra de negócio.** O resumo afirma que `fare_amount` “é função da distância” e sugere interpretação operacional a partir de correlação observacional; a própria seção de limitações reconhece que correlação não implica causalidade.
9. **Médio — interpretação geográfica sem mapeamento.** ZIPs na faixa 10.000–11.000 são chamados de NYC e extremos são tratados como outliers espaciais sem lookup/mapeamento geográfico no notebook.
10. **Médio — análise temporal material permanece como próximo passo.** Apesar de duas colunas timestamp, o run não explora padrões horários/semanais na análise corrente, apenas os recomenda depois.
