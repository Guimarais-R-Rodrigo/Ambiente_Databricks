2. **Médio — inferência geográfica não demonstrada.** O texto associa os top ZIPs ao “centro de Manhattan tipicamente” sem lookup geográfico ou outra evidência persistida.
3. **Médio/alto — “sazonalidade” não é demonstrada.** Há apenas dois meses; janeiro tem 10.867 viagens e fevereiro 11.065, com tarifa média idêntica de 12,35. Isso não estabelece sazonalidade.
4. **Médio — limitação contradiz o cálculo.** O handoff diz que “estatísticas [foram] calculadas sobre a tabela completa”, mas a célula de distribuições usa `WHERE trip_distance > 0` e `WHERE fare_amount > 0`; portanto esses percentis/médias excluem observações não positivas.
5. **Médio — amostra realizada é comunicada como 1% exato.** `.sample(fraction=0.01, seed=42)` é Bernoulli; o run mede 246 linhas, mas não mede o denominador filtrado para demonstrar que 246 corresponde exatamente a 1,00%.
6. **Médio — percentual arredondado pode esconder violações raras.** `pct_invalid_duration` é arredondado a duas casas; `0.00%` não prova zero linhas inválidas quando o denominador é 21.932.
7. **Médio — unidade de distância/tarifa não é comprovada pelo artefato.** “milhas” e “US$” são usados em labels sem metadado de unidade exibido no notebook.
8. **Médio — declaração sobre outliers é imprecisa.** O handoff diz que valores extremos foram filtrados para visualização, mas os limites superiores do scatter (`trip_distance < 100`, `fare_amount < 500`) estão acima dos máximos observados nas estatísticas positivas (30,6 e 275); o filtro efetivo relevante é a remoção de valores não positivos.
