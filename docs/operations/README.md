# Operações autônomas

Esta pasta contém governança operacional que coordena agentes sem substituir ADRs, contratos de campanha ou policy de produto.

## Documentos

- [CODEX_AUTONOMOUS_PROTOCOL.md](CODEX_AUTONOMOUS_PROTOCOL.md) — state machine e regras do controller.
- [CODEX_AUTONOMOUS_RETROSPECTIVE.md](CODEX_AUTONOMOUS_RETROSPECTIVE.md) — lições operacionais extraídas das tentativas B1.
- [CODEX_AUTONOMOUS_START_PROMPT.md](CODEX_AUTONOMOUS_START_PROMPT.md) — prompt curto para iniciar uma sessão autônoma.
- [autonomy/](autonomy/) — schema e envelopes por frente.

O protocolo não concede autoridade. Autoridade vem de um envelope ativo com fonte humana verificável.
