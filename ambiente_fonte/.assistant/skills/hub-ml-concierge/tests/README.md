# Testes de manutenção do Concierge

Este diretório contém instrumentos de manutenção, não uma etapa obrigatória para o usuário do ambiente. Para usar a skill, volte ao [guia](../README.md). A [matriz de casos](casos_aceite.json) contém expectativas, não resultados observados.

Os comandos de testes do runbook pertencem à raiz do checkout de autoria; `tools/tests` não é ferramenta distribuída do produto. Registre caso, commit/versão, ambiente, skill observada, recursos lidos, resultado, motivo e limites. Use `PASS`, `FAIL`, `BLOQUEADO` ou `NÃO VERIFICADO`; não transfira o resultado de outra skill.
