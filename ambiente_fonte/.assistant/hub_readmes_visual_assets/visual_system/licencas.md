# Licenças e proveniência

Os diagramas deste diretório são composições originais do projeto, construídas
por código com formas geométricas e tipografia do sistema. Não incorporam
fotografias, ilustrações, logotipos ou ícones de terceiros.

A fonte de geração é `tools/render_readme_visuals.mjs`. Os arquivos SVG e PNG
devem permanecer sincronizados com ela.
